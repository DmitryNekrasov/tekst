u8

val String.u8: Utf8String(source)

The UTF-8 encoding of this string. The utf8-string compiler plugin encodes .u8 on a constant string at compile time, and gives the U8_NOT_CONSTANT warning for .u8 on any other string. A call through a reference such as String::u8 encodes at run time, with no warning.

Samples

val text = "Hi 👋🏽".u8
assertEquals(4, text.length)
assertEquals(11, text.byteCount)
assertEquals("Hi 👋🏽", text.toString())
