Grapheme

class Grapheme(source)

An extended grapheme cluster of a Utf8String (UAX #29), what a user sees as one character. A grapheme does not copy its bytes, so it can keep all the bytes of its string in memory.

Samples

val family = "👨‍👩‍👧".u8
val grapheme = family.graphemes.single()
assertEquals(8, grapheme.toString().length) // 3 people and 2 zero width joiners, 8 UTF-16 chars
assertEquals(family, grapheme.toUtf8String())
